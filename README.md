# Maternal & Fetal Health Prediction System

## Project Description

This project predicts:

- Maternal Health Risk
- Fetal Health Status

using Machine Learning and Streamlit.

## Technologies Used

- Python
- Streamlit
- Scikit-Learn
- NumPy
- Pandas
- Joblib

## Models Used

### Maternal Health
Decision Tree
Accuracy: 81.77%

### Fetal Health
Random Forest
Accuracy: 94.60%

## Run the Project

```bash
py -m streamlit run app.py
```
